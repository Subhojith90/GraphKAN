# Stage 4B v2 Hotfix

The v1 package failed before VMC evolution because the Stage 4B runner passed a NetKet `LocalOperatorJax` object to `MetropolisLocal`, which requires the Hilbert space. No valid science rows were generated by v1.

Version 2 changes the sampler call to `MetropolisLocal(hi, ...)`, where `hi` is the Hilbert object returned by `build_netket_rydberg_operator`. It also registers `smooth_endpoint_sum_jastrow` as an explicit RBF basis-family model.

Run all Stage 4B batches with `--overwrite`; the v1 failed rows are not evidence and must not be retained.
