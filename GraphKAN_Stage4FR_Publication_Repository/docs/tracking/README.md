# Research history and repository tracking

This directory keeps historical material out of the repository root while
preserving the provenance needed for supervisory and publication review.

## Contents

- `stage4f/` — Stage 4F.1, 4F.1b, and 4F.1c handoff documentation
- `stage_history/` — earlier stage protocols, decisions, hotfixes, and repair logs
- `changelogs/` — stage-specific change records
- `execution_logs/` — retained human-readable execution transcripts

Canonical machine-readable run evidence remains under the corresponding
`results_stage*` directories. Files in this tracking directory are explanatory
records and should not replace registry or filesystem validation.
