# Reports

The `stage4fr_final_20260721` directory is regenerated directly from the
canonical `results_stage4f_r/frozen` campaign using
`scripts/finalize_stage4fr_publication.py`.

It contains analysis tables, figures, checksums, and machine-readable gate
summaries intended for review. The visually verified supervisory PDF is stored
under `output/pdf/`. Canonical raw run evidence remains under
`results_stage4f_r/frozen` and is validated independently.
