# GraphKAN AMO NQS v1.0.0

This is the first public archival release of the GraphKAN AMO NQS benchmark and
reproducibility package supporting the manuscript *Boundary Conditioned Pair
Jastrow Neural Quantum States for Open Rydberg Chains*.

## Included evidence

- Frozen 960 run ten site campaign across open and periodic boundaries
- Strict campaign integrity validation and independent Linux replay
- Twelve site continuation and convergence controlled confirmation
- Gauge analysis and orthogonal endpoint counterfactual
- Deterministic manuscript analysis, figures, tables, tests, and checksums
- Complete November 2026 master evidence archive

## Scientific scope

The release supports an observable dependent and protocol dependent
representation effect on the registered ten site grid. It does not establish
general KAN superiority, Graph KAN superiority, a universal boundary law, or a
system size scaling law. The separate twelve site continuation does not recover
the joint density and connected correlation benefit seen under the primary ten
site protocol.
